# Ethics in these labs

Key themes:
- Privacy-by-design: data minimization, retention, logging hygiene
- Security as user protection: least privilege, secure defaults, auditability
- Automated moderation: false positives/negatives, transparency, accountability
- Operational ethics: avoiding outages and harm caused by unnecessary complexity

Prompts:
- If a system is anonymous, what should we still avoid storing?
- What audit evidence is needed without collecting excessive personal data?
- How do we prevent "silent failure" in moderation and event workflows?
